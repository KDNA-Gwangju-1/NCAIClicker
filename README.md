# NCAIClicker

NCAI 과정 팀 프로젝트(자유 주제) — 5인 7일간 Unity로 제작하는 스태미나 기반 인크리멘탈 게임. 게임명·비주얼 테마는 미정이며, 저장소명으로 `NCAIClicker`를 임시로 쓴다.

## 문서

- [게임 기획서 (GDD)](docs/GDD.md)
- [5인 7일 실행 계획](docs/EXECUTION_PLAN.md)
- [아키텍처 및 프로파일링 계획](docs/ARCHITECTURE.md)

## 시작하기

1. `docs/EXECUTION_PLAN.md`의 역할 분담에서 본인 담당을 확인한다.
2. `docs/ARCHITECTURE.md`의 공용 인터페이스·매니저 목록을 먼저 읽는다 — Day 1 이후 임의 변경 금지.
3. 작업은 `feature/<모듈>-<이슈번호>-설명` 브랜치에서 진행하고, PR 리뷰 1명 승인 후 Squash and merge한다 (`docs/EXECUTION_PLAN.md`의 PR 리뷰·머지 규칙 참고).
