# UI 디자인 및 가이드라인 정본

이 문서는 NCAIClicker 프로젝트의 사용자 인터페이스(UI) 제작, 배치, 연출 시 준수해야 하는 정량적 수치와 설계 원칙을 규정하는 정본입니다.
규칙의 출처는 WCAG 2.1 AA 웹 접근성 표준 및 모바일·데스크톱 UI 가이드라인을 기반으로 합니다.

## 1. 기준 해상도 및 화면 영역

* **기준 해상도**: 1920x1080 (16:9 비율 고정)
* **Canvas Scaler 설정**:
  * Scale Mode: Scale With Screen Size
  * Reference Resolution: X 1920, Y 1080
  * Screen Match Mode: Match Width Or Height (0.5 기본값)
* **타이틀 세이프존 (Title Safe Zone)**:
  * 전체 화면의 90% 영역 유지
  * 가로 유효 영역: 1728px (좌우 여백 각 96px)
  * 세로 유효 영역: 972px (상하 여백 각 54px)
  * 핵심 텍스트, 주요 상태 정보, 조작 버튼은 90% 안전 영역 바깥으로 이탈하지 않아야 합니다.

## 2. 간격 및 크기 시스템 (4배수 그리드)

일관된 시각적 리듬과 정렬을 위해 모든 크기, 패딩, 마진, 요소 간격은 4의 배수를 기본 단위로 사용합니다.

* 기본 스케일 단위: 4px
* 표준 간격 단계:
  * 4px: 극소 여백 (텍스트와 인라인 아이콘 사이 등)
  * 8px: 최소 패딩 (버튼 내부 상하 패딩, 좁은 행 간격)
  * 12px: 기본 패딩 (작은 카드 내부 여백)
  * 16px: 표준 컴포넌트 간격 (일반적인 카드 내부 마진)
  * 24px: 섹션 내부 그룹 간격
  * 32px: 섹션 간 기본 여백
  * 48px: 대형 레이아웃 구분 여백
  * 64px: 화면 외곽 마진 또는 주요 탭 구분 간격

## 3. 타이포그래피 (글자 크기)

TextMeshPro 폰트 크기 기준입니다. 가독성 저하를 방지하기 위해 정해진 계층에 맞는 최소 크기를 준수합니다.

* **본문 텍스트 (Body)**: 최소 24px 이상
* **캡션 및 보조 텍스트 (Caption)**: 20px (부연 설명 등 제한된 용도로만 사용)
* **소제목 (Subheading)**: 28px ~ 32px
* **강조 및 대제목 (Heading / Highlight)**: 36px 이상

## 4. 명도 대비 (Contrast Ratio) 및 가독성

WCAG 2.1 AA 기준을 적용하며, `UiGuidelineChecks`를 통해 자동 검증합니다.

* **일반 본문 텍스트**: 최소 **4.5:1** 이상
* **대형 텍스트 (36px 이상 또는 28px 이상 Bold)**: 최소 **3:1** 이상
* **비텍스트 UI 요소 (테두리, 행 구분선, 상태 표시선)**: 최소 **3:1** 이상
* **비활성화 요소 면제**: 비활성(Disabled / interactable=false) 상태의 텍스트 및 UI 요소는 WCAG 1.4.11 규정에 따라 대비 검사에서 제외됩니다.

### 상대 휘도 (Relative Luminance) 계산 공식

sRGB 색 공간의 각 채널 R, G, B (0.0 ~ 1.0)에 대해 감마 보정을 수행합니다.

1. 각 채널별 선형화:
   * 채널 값이 0.04045 이하인 경우: C_lin = C / 12.92
   * 채널 값이 0.04045 초과인 경우: C_lin = ((C + 0.055) / 1.055) ^ 2.4
2. 상대 휘도 계산:
   * L = 0.2126 * R_lin + 0.7152 * G_lin + 0.0722 * B_lin
3. 명도 대비 계산:
   * Contrast Ratio = (L1 + 0.05) / (L2 + 0.05) (단, L1은 더 밝은 색상의 휘도, L2는 더 어두운 색상의 휘도)

## 5. 핵심 디자인 원칙

### (1) 색상 단독으로 의미를 전달하지 않는다
* 적자, 손실, 오류 등 특정 상태를 붉은색 등 색상만으로 구별하게 해서는 안 됩니다.
* 색상과 함께 부호 (+ 또는 마이너스), 명시적 텍스트 레이블, 아이콘을 병행 표기해야 합니다.

### (2) 알파 채널 투명도로 톤을 만들지 않는다
* `Image.color.a`를 조절하여 반투명하게 만드는 경우 뒤에 깔리는 배경색에 따라 명도 대비가 무너집니다 (실제 #34에서 발생한 문제 원인).
* UI 배경 및 요소는 투명도가 없는 불투명 단색(Solid Color) 팔레트로 정의하여 사용합니다.

### (3) 최소 클릭 타깃 크기 44px 확보
* 마우스 클릭 및 터치 조작의 정확성을 보장하기 위해 Button 등 인터랙션 요소의 가로 및 세로 크기는 최소 44px 이상이어야 합니다.

### (4) 팔레트 상수의 용도별 분리
* 테두리용 색상과 텍스트용 색상은 목적이 다르므로 상수를 분리하여 선언합니다.
* 테두리 전용 어두운/밝은 색상을 텍스트에 오용하여 발생하는 저대비 결함을 사전에 방지합니다.

## 6. 자동 검증 연동

* 이 가이드라인의 정량 규칙(명도 대비, 글자 크기, 클릭 타깃, 세이프존, 알파 톤)은 `UiGuidelineChecks`에 의해 자동으로 검사됩니다.
* 전체 검증 메뉴 `NCAI > 전체 검증 실행`을 통해 통합 검사를 수행할 수 있습니다.
