미등록 항목은 실루엣과 이름을 가린다. 등록 조건만 보여 준다.

수집 대상은 targets.csv 4종(이슈의 "우리는 저금통 종류가 자연스럽다")으로 그렸다. 보너스 종류는 원작 툴팁(컬렉션 코인 +1% / 듀오 코인 +2개)을 저금통에 옮긴 예시이며 수치·효과 모두 미정이다 — 효과를 주면 #176 밸런스 재계산의 입력이 하나 는다. "효과 없이 열람만" 으로 결정되면 보너스 행과 상단 합계 알약만 뺀다.

이 목업에 없는 것: 상점·도감 탭이 붙는 고지서 화면 본체(이미 구현됨, billing.md), 반지 탭(#183 구현됨), 구매 확인창. 원작의 5탭 중 "저금통" 탭은 우리에게 대응물이 없어 넣지 않았다.
