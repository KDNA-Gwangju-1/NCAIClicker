# UI 목업

화면 시안을 **독립 실행 HTML 한 장**으로 두는 곳이다. 브라우저로 파일을 열면 바로 보인다 —
유니티도 계정도 필요 없다. 팀원 누구나, 어떤 도구를 쓰든 확인할 수 있게 하려는 것이 목적이다.

## 규칙

- 파일 하나 = 화면 하나 묶음. 이름은 **kebab-case ASCII** (`pause-menu.html`)로,
  같은 기능의 `docs/TECH_NOTES/` 문서와 이름을 맞춘다.
- **기준 해상도 1280x720** (16:9). 1920x1080 으로 올릴 때는 1.5배 한다.
- 색·치수의 **정본은 이슈 본문과 댓글**이다. 이 폴더의 HTML 은 그것을 눈으로 확인하는 용도다.
  숫자가 어긋나면 이슈가 맞다.
- 목업은 **구현물이 아니다.** 버튼은 눌러도 동작하지 않는다. 동작이 필요하면 유니티에서 만든다.
- 밸런스 수치는 박지 않는다. CSV 가 원본이므로 `[값]` 으로 비워 둔다.
- 구현이 끝나 화면이 실제와 달라지면 **목업을 지우고** `docs/TECH_NOTES/` 문서로 대체한다.
  낡은 시안이 남아 있으면 어느 쪽이 맞는지 아무도 모른다.

## GitHub 웹에서는 렌더링되지 않는다

GitHub 은 저장소 안의 HTML 을 **소스 코드로만** 보여 준다. 화면으로 보려면 둘 중 하나다.

- 저장소를 받은 뒤 파일을 브라우저로 연다 (권장)
- 또는 `https://htmlpreview.github.io/?<파일의 raw URL>` 로 연다
