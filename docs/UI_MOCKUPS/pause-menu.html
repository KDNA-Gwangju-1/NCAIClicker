이슈 #192 의 시안이다. 기준 해상도 1280×720 (16:9). 1920×1080 으로 올릴 때는 1.5배 한다. 색·치수의 정본은 이슈 본문의 레이아웃 명세 댓글이며, 이 파일은 그것을 눈으로 확인하는 용도다.

구현물이 아니다. 버튼은 눌러도 아무 일도 일어나지 않는다.
