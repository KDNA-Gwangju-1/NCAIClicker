### 1. 오프닝

화면: 크리처를 부수고 코인이 튀는 장면 3~4컷을 빠르게 이어 붙인다.

```
NCAIClicker
커서만 올려라. 망치는 알아서 내려친다.
```

### 2. 팀 정보

화면: 검은 배경 텍스트 슬라이드.

```
2조
김성훈 · 강찬양 · 김훈일 · 김창준 · 정야후

```
담당을 고정하지 않고 이슈를 나눠 가져갔습니다

### 5. 시작 → 플레이 → 결과 (한 판 통째로)

화면: 끊지 않고 이어서 녹화한다. 필요하면 배속으로 줄이되 장면을 건너뛰지 않는다.
**평가 기준 "게임이 정상 동작함"의 핵심 근거라서 컷 편집을 최소화한다.**

## 문제·해결 사례 후보

고른 기준: **셋이 서로 다른 층위**(팀 운영 / 협업 도구 / 게임 로직)여야 하고, 이슈로 근거가 남아 있어 화면에 캡처로 보여 줄 수 있어야 한다.

### 추천 1 — 자유롭게 가져가니 둘이 같은 일을 잡았다 (팀 운영)

역할을 고정하지 않은 방식(7-2)의 **후속편**이라 흐름이 자연스럽다. "이렇게 했다"로 끝나지 않고 "그랬더니 이런 문제가 생겼고 이렇게 고쳤다"까지 가서 설득력이 생긴다.

```
누구나 이슈를 가져가자
두 사람이 같은 일을 잡거나 작업 번호가 겹쳤습니다
```
```
원인: 가져간 뒤 보드 상태를 늦게 바꿔
다른 사람 눈에는 비어 있는 일로 보였습니다
```
```
해결: 가져가는 즉시 '진행 중'으로 바꾸고
선행 작업을 적어 착수 가능 목록을 자동 계산했습니다
```
근거: 작업 번호 중복 (6.32 #287·#290, 6.35 #309·#311), 중복 검출 자동화 #81, 진행 현황 대시보드

### 추천 2 — 병합했더니 남의 작업이 소리 없이 사라졌다 (협업 도구)

Unity 협업에서 누구나 겪는 문제라 공감을 얻기 쉽다. "에러 없이 사라졌다"는 점이 강하다.

```
같은 프리팹을 두 사람이 고친 뒤 병합하자
다른 팀원이 넣은 오디오 매니저가 사라졌습니다
```
```
원인: Unity 전용 병합 도구가 설정돼 있지 않아
한쪽 파일을 통째로 고르는 수밖에 없었습니다
```
```
해결: 병합 도구를 설정하고
남의 씬은 고치지 않고 프리팹으로 넘기는 규칙을 세웠습니다
```
근거: #152 (발단 #151, 사라진 것 #36)

### 추천 3 — 버그처럼 보였지만 계산은 맞았다 (게임 로직)

"고쳐서 없앴다"가 아니라 **원인을 끝까지 추적해 보니 버그가 아니었다**는 반전이 있다. 수치가 눈에 보여 영상으로 전달하기 좋다.

```
파산 직후 첫날 수입이 비정상적으로 크게 나와
새 광석이 첫날 한꺼번에 해금됐습니다
```
```
원인: 정산 화면에 $1,000 코인 칸이 빠져 합계가 틀려 보였고,
철광석이 드물게 $1,000을 뽑아 해금이 운에 달려 있었습니다
```
```
해결: 코인 칸을 데이터에서 만들도록 바꾸고
광석별 최대 코인을 CSV로 제한했습니다
```
근거: #326, #330, PR #333
