# 새 스크립트 만들기

0. **작업 브랜치가 아직 없으면 여기서 멈추고 `start-work` 스킬부터 실행한다.**
   `AGENTS.md` 의 "작업 순서 (필수)" 0번 — 이슈 배정 / 칸반 In Progress / `Develop` 에서 브랜치.
   `main` 이나 남의 브랜치 위에서는 파일을 만들지 않는다.
1. `AGENTS.md` 의 **"지켜야 할 규칙"** 과 `docs/ARCHITECTURE.md` 의 해당 절(2절 인터페이스 / 3절 이벤트)을 읽는다.
   담당 모듈이 정해져 있으면 `AGENTS.md` 의 "모듈별로 읽혀야 할 것" 표를 따른다.
2. **아래를 계획으로 보여 주고 승인을 받는다. 승인 전에 파일을 만들지 않는다.**
   - 스크립트 이름과 둘 폴더 (`Assets/Scripts/Runtime/<모듈>/`)
   - 필드와 메서드 목록, 각각 하는 일
   - 구독할 `GameEvents` 이벤트와 발행할 이벤트
   - 새로 만들어야 하는 폴더가 있으면 그 폴더
   - 공용 계약(인터페이스·이벤트·CSV 스키마)을 **건드려야 하면 여기서 멈추고 이슈 발의를 제안한다.** 구현하지 않는다.
3. 승인을 받으면 스크립트를 만든다. **기능은 이슈 범위 안에서 요청받은 만큼만** 채운다.
4. `convention-checker` 에이전트에게 만든 파일을 점검받고, 결과를 함께 보고한다.
5. 만든 컴포넌트를 씬의 오브젝트에 붙이는 일은 하지 않는다. **어느 오브젝트에 붙이면 되는지만 안내한다.**
   자기 담당이 아닌 씬은 열어서 보되 저장하지 않는다.

이 파일과 `AGENTS.md` 의 내용이 다르면 `AGENTS.md` 를 따른다.
